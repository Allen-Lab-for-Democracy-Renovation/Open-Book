# OpenBook Wiki

Welcome to the OpenBook documentation. OpenBook is a free, open-source budget transparency portal for municipalities. This wiki contains step-by-step guides for everyone involved in setting up and using OpenBook.

![The public portal, showing the banner, headline figures, and sections for expenses, revenues, and capital](https://raw.githubusercontent.com/Allen-Lab-for-Democracy-Renovation/Open-Book/main/docs/screenshots/portal-overview.png)

## About OpenBook

OpenBook is maintained by the Allen Lab for Democracy Renovation. The source code is available at [github.com/Allen-Lab-for-Democracy-Renovation/Open-Book](https://github.com/Allen-Lab-for-Democracy-Renovation/Open-Book).

## Reporting a Problem

If something doesn't work the way these guides say it should, please tell us — every report makes OpenBook better for the next town.

**Open an issue on GitHub:** [github.com/Allen-Lab-for-Democracy-Renovation/Open-Book/issues/new](https://github.com/Allen-Lab-for-Democracy-Renovation/Open-Book/issues/new). A free GitHub account is all you need. Include what you were trying to do, what happened instead (with the exact error message if there was one), the page's web address, and a screenshot if you can — but crop out anything you wouldn't want public, since issues are visible to everyone.

**Or email:** if you'd rather not use GitHub, or the problem involves something sensitive, contact Sarah Hubbard at [sarah_hubbard@hks.harvard.edu](mailto:sarah_hubbard@hks.harvard.edu).

## Contributing

OpenBook is built for Massachusetts municipalities, by people who want budgets to be understandable. Contributions of every kind are welcome: code, documentation, sample data from your town's accounting system, design feedback, or just a note about what confused you.

To get involved, reach out to Sarah Hubbard at [sarah_hubbard@hks.harvard.edu](mailto:sarah_hubbard@hks.harvard.edu). If you're comfortable with Git, the README's "Reporting problems and contributing" section describes the pull-request flow; these wiki pages live in the repository's `docs/wiki/` folder and are published here automatically, so documentation fixes are pull requests too.
